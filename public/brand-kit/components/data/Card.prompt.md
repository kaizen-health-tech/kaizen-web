**Card** — the base surface for grouped content: records, insights, settings sections. White fill, cloud hairline, soft shadow, 20px radius.

```jsx
<Card>
  <h3 className="kz-title-md">Blood pressure</h3>
  <p className="kz-body-md">Last reading 118/76</p>
</Card>
```
Set `elevated={false}` for a flat card inside an already-elevated surface.
